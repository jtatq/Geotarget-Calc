# GT Pricing

Standalone static package-pricing calculator served at `https://pricing.geotargetus.dev/` and launched from the Application Control Center.

The application is intentionally self-contained in `index.html`. The current production file was captured from `/var/www/pricing/index.html` on 2026-08-26 without modifying the live site.

Open `index.html` directly for local review, or serve the repository with any static HTTP server.
